# 掼蛋牌室 · Miai

适用于 GitHub Pages 的中文掼蛋前端。页面直接连接 Miai 原站房间服务，支持单人、好友组队、房间号互通和刷新续局。

## 启动和部署

在此目录运行 `python3 -m http.server 8000`，打开 [本地牌室](http://localhost:8000/)。

将文件推送到 GitHub 仓库的 `main` 分支，在仓库的 **Settings → Pages → Build and deployment** 选择 **GitHub Actions**，然后触发 **Deploy GitHub Pages** 工作流。站点资源使用相对路径，房间使用 `#/room/房间号` 路由，可直接打开或刷新 GitHub Pages 项目子路径下的邀请链接。

## 牌桌操作

- **排序**按掼蛋牌力从大到小排列，同点数竖叠。点击按钮可清除组合锁定。
- **理牌**会独立摆放选中的合法牌型。点击组合名称可选中整组，再点「理牌」解锁。组内有牌离手后会解除该组锁定。
- **智能理牌**保留手动锁定，从剩余手牌中按规则提取炸弹和较大的组合，再按点数堆叠。
- **同花顺提示**列出手牌可组成的同花顺，包含百搭补位。点击提示可选牌。
- **自动选牌**按原站给出的可出牌列表挑选最小压制组合，领出时选最小单张。选中后仍需点击「出牌」确认。百搭存在多种声明时可在牌型下拉框选择。
- **记牌器**从双副牌扣除自己手牌和已打出的牌，展开可看各花色数量。进还贡公开的牌显示在收牌方手牌前方，打出后隐藏。
- **对局历史**可查看当前手的进还贡和出牌、本局战绩、本浏览器保存的结算记录。原站回放就绪后，本局战绩提供回放入口。

房间席位凭证、手牌整理和历史保存在当前站点的浏览器存储中。用同一浏览器、同一站点打开最近房间即可续局。和原站玩家一起玩时可分享六位房间号。

[openapi.json](openapi.json) 提供牌型和评分规则。对局使用原站房间 HTTP 接口和 WebSocket 协议 2，由原站校验动作并运行 Miai。
